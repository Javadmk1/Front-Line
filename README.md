# Front Line

A lightweight offline 2D strategy game prototype built with Godot 4 for Android.

## Current prototype
- One playable test battle
- 15 connected territories
- Tap a friendly territory, then an adjacent territory to move or attack
- End-turn button for enemy AI
- Offline gameplay; no server required

## Build
GitHub Actions attempts to export a debug Android APK and uploads it as a workflow artifact. Open **Actions**, select **Build Android APK**, and inspect the run. A successful run provides a downloadable `FrontLine-Android-Debug` artifact.

This is an early prototype, not a release-ready or signed-for-store APK.
